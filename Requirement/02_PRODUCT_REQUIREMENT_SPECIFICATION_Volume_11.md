# REOS Product Requirement Specification

# Volume 11

## Enterprise Reports & Analytics Catalog

Version: 1.0

------------------------------------------------------------------------

# 1. Objective

Every report must support:

-   Company
-   Branch
-   Project
-   Phase
-   Team
-   Executive
-   Agent
-   Date Range

Reports must support export to PDF, Excel and CSV.
